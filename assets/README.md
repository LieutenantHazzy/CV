# Foto's

Zet hier je cv-foto in. `config.example.json` wijst naar `assets/photo.jpg`, maar
elk gangbaar formaat werkt: `.png`, `.jpg`, `.jpeg`, `.webp` en `.gif`.

De foto wordt als base64 in de html ingesloten, dus je cv blijft één bestand dat je
kunt mailen zonder dat er iets ontbreekt. Lees hier verder over formaat, grootte en
de kadersectie: de README.

Deze map staat in `.gitignore`, behalve dit bestand. Je foto is persoonlijke data en
gaat dus niet mee naar een publieke repository.
